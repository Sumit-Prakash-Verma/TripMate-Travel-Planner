
# ✈ TripMate - Travel Planner

## About Project
TripMate is a travel planning web application that helps users
create, manage, and share their travel plans.

It also uses AI to generate travel itineraries.

## Technologies Used
- Java
- Spring Boot
- Spring Security
- MySQL
- HTML
- CSS
- JavaScript
- Ollama AI
- Qwen 2.5:7b

## Features
- User Registration and Login
- User Authentication
- AI Travel Itinerary Generation
- Create New Trips
- View My Trips
- Edit Trips
- Delete Trips
- Save Itineraries
- Invite Members
- View Shared Trips
- Remove Members

## Database
Database Name: travel_planner

Tables:
- app_users
- trips
- saved_itineraries
- trip_members

## AI Configuration
AI Provider: Ollama  
Model: qwen2.5:7b

Ollama should be running locally for AI itinerary generation.

## Run Project
1. Start MySQL.
2. Start Ollama.
3. Make sure the configured AI model is available.
4. Open the project in VS Code or IntelliJ.
5. Run the Spring Boot application.
6. Open your browser and visit:

http://localhost:8081
